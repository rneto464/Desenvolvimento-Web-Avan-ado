📰 Painel de Notícias - São Luís

Aplicação frontend desenvolvida em React.js para exibição de notícias da cidade de São Luís - MA. O sistema consome uma API REST desenvolvida em Node.js (Express), permitindo listar, visualizar e filtrar notícias em tempo real.

🚀 Tecnologias Utilizadas
React.js (Vite)
JavaScript (ES6+)
Axios
React Router DOM
CSS / Tailwind (ou outro framework de estilo)
🎯 Objetivo do Projeto

Desenvolver uma interface moderna, responsiva e intuitiva para consumo e exibição de notícias locais, com foco em:

Usabilidade
Performance
Organização de código
Integração com API
⚙️ Funcionalidades
📄 Listagem de notícias
🔍 Busca por palavras-chave
🗂️ Filtro por categorias
📖 Visualização detalhada da notícia
🔄 Paginação ou scroll infinito
⚠️ Tratamento de erros e loading
